# Локальная конфигурация и секреты DictAI

## Что хранится в Git

`.vscode/launch.json` и `.vscode/launch.example.json` содержат только безопасную
конфигурацию запуска. В них нет Anthropic credential, JWT, пароля или настоящего
токена. Пример не требует ключа Anthropic. Не вставляйте рабочие значения в эти
файлы, task/review-записи, скриншоты, логи или команды с историей shell.
В текстовых примерах секретных полей допустим только placeholder вида
`<LOCAL_ONLY_VALUE>`; текущий JSON намеренно не содержит секретного аргумента.

Сейчас `API_BASE_URL` в примере — локальный адрес без credentials. Текущий
`lib/shared/providers/providers.dart` задаёт backend URL в коде и не читает этот
dart-define; настройка gateway будет реализована отдельно в TASK-FE-001.05.
Пример запуска сам по себе не переключает backend на localhost.

## Anthropic и локальный ввод

Текущий `AnthropicService` получает ключ из `SecureStorage`, а не из
`ANTHROPIC_API_KEY`/`ANTHROPIC_MODEL` dart-defines. `ChatPanel` сейчас не подключён
к экранам; прямой чат не входит в обязательный batch scope. Для текущей работы
с backend DictAI Anthropic key не требуется, поэтому его не нужно возвращать
в конфигурацию запуска.

Существующий UI ввода ключа в неподключённом ChatPanel не является рекомендуемым
хранилищем для production credentials: нынешний `SecureStorage` использует
SharedPreferences. Переход JWT на OS secure storage предусмотрен TASK-FE-001.04;
данная задача не меняет storage и не включает чат.

Если отдельно согласованной функции позднее потребуется секрет, сначала
определите её контракт и защищённый способ локального ввода. Не передавайте
production provider key в tracked-конфигурации или сборочных dart-defines.

## Локальные файлы и .gitignore

Игнорируются `.env`, `.env.*`, `.vscode/*.local.json`, `.vscode/*.local.env`,
`.vscode/.env` и `.vscode/.env.*`. Только безопасные `.env.example`/`.env.template`
могут быть опубликованы. Создавать такие файлы для текущего запуска не требуется.
Имена `*.local.json` и `.env` здесь — правила исключения из Git, а не обещание
автоматической загрузки: в текущем приложении нет env-loader, VS Code не читает
`launch.local.json` автоматически.

`.gitignore` не защищает уже отслеживаемые файлы: `launch.json` остаётся tracked.
Проверяйте состав `git diff --cached` перед публикацией. Не используйте `git add -f`
для локальных credentials. Существующие source/DTO и зависимости задачей не меняются.

## Действия владельца потенциально раскрытого ключа

В исходной tracked-конфигурации находилось значение в формате Anthropic API key;
оно уже было в Git и удалено только из текущей конфигурации ветки .02. Значение
в этой документации и проверках не воспроизводится; его действительность и
принадлежность не проверялись запросами к provider.

Владелец должен считать credential потенциально раскрытым, отдельно выполнить
revoke/rotation у provider и проверить его использование/расходы в доступном ему
аккаунте. Если интеграция больше не нужна, новый ключ создавать не требуется.
Удаление строки из дерева не отзывает ключ и не удаляет его из Git history,
клонов или старых веток. Переписывание истории/force push данной задачей не разрешены.

В Result TASK-FE-001.02 и release gate TASK-FE-001.42 фиксируется только безопасное
evidence владельца: дата, действие и подтверждение без значения credential.
До получения такого evidence security release gate остаётся открытым. Агент
не отзывает credential, не входит в аккаунт provider и не объявляет rotation
выполненной. Приёмка локального исправления не подтверждает внешний отзыв ключа.

## Проверки

Перед публикацией проверяются tracked и предлагаемые untracked-файлы, включая
удалённые строки diff: выводятся только пути, строки и типы findings, значения
редактируются. Отдельно проверяются JSON, правила ignore и отсутствие изменений
в `lib/`, `macos/`, `linux/`, `test/`, API/DTO и dependencies. Flutter build/test
для изменения конфигурационных примеров не требуется и не доказывает отзыв ключа.

Фактические команды, результаты, независимый review и ограничения находятся
в [TASK-FE-001.02](../ai/tasks/TASK-FE-001.02.md).
